# 平台原生库目录

本目录用于存放随应用发布的高性能平台原生库。目录结构按运行时标识符划分：

```text
native/
  win-x64/
  win-arm64/
  linux-x64/
  linux-arm64/
  osx-x64/
  osx-arm64/
```

构建和发布时，`native/**` 下的文件会复制到输出目录。程序启动后会根据当前运行平台自动注册对应目录，并由 `NativeBootstrap` 按平台解析 `dll`、`so` 或 `dylib`。

库选型应遵循项目原则：优先选择目标系统下性能最好、稳定成熟、最适合本项目采集、解析、显示、压缩和存储链路的库。具备 GPU 加速条件的库，应优先提供 GPU 实现，并保留 CPU 兼容回退。
